# Тыквенная ночь PRO.FINANSY

Хэллоуинский сайт: игра «Поймай тыквы» → переход с дымом → скретч-карта с подарком.

- `index.html` — вся страница одним файлом (стили и скрипт внутри), картинки берёт из `assets/`.
- `assets/` — оптимизированные картинки (WebP) и музыка. Это то, что грузит сайт.
- `source/` — исходники картинок в полном качестве.
- `tools/` — скрипты, которыми картинки вырезались из чёрного фона и сжимались.

## Настройки (в начале скрипта в `index.html`)

| Константа | Что делает |
|---|---|
| `BOT_URL` | ссылка на бота для кнопки «Забрать подарок» |
| `GIFT_TITLE`, `TICKETS` | текст подарка на билете |
| `GOAL` | сколько тыкв надо поймать |
| `MISS_PENALTY` | отнимает ли промах пойманную тыкву |
| `STAY_START`, `STAY_MIN`, `STAY_STEP` | скорость игры |
| `MUSIC_VOLUME` | громкость музыки |

## Проверка локально

```bash
python3 -m http.server 5173
```

Открыть `http://localhost:5173/`. Для разработки: `#play` — пропустить заставку, `#s2` — сразу второй экран.
